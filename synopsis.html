Project Overview

Digitizing workshop tool management to enhance efficiency and transparency in technical institutes.

Abstract

The central workshop is a core facility in technical institutes, yet tool management often remains a manual, error-prone process. This leads to issuance delays, poor tracking of availability, tool loss, and inaccurate records. The Central Workshop Management System is a web-based solution to automate this process. It provides distinct interfaces for students to request tools and for administrators to manage inventory and approve requests. Utilizing a Node.js/Express backend, MySQL database, and secure OTP login, the system eliminates paperwork, improves transparency, and saves time for everyone involved.

The Proposed System: An Interactive Workflow

This web application eliminates manual processes with an intuitive online portal. Click on each step below to see how the system works.

1. User Authentication

Users (students) and admins sign up and log in securely via an OTP sent to their email or phone.

↓

2. Tool Request

Students browse available tools and submit a request to borrow an item through the user dashboard.

↓

3. Admin Approval

The administrator views the request on their dashboard and can approve or deny it based on availability.

↓

4. Real-time Database Update

Upon approval, the available tool count is automatically decremented in the database. When returned, it's incremented.

User Authentication

The system ensures secure access by requiring all users to authenticate themselves. New users can sign up, and existing users can log in using a One-Time Password (OTP). This prevents unauthorized access and ensures that all requests are tied to a verified user account, which is the first step in creating a transparent and accountable system.

User Module

This module handles all student-facing functionality.

  • Secure Login/Signup via email OTP.
  • View all available tools and their current quantities.
  • Send, track, and manage tool borrowing requests (Pending, Approved, etc.).
  • Initiate the tool return process after work is complete.

Admin Module

This module provides administrators with complete control over the workshop's inventory and requests.

  • Secure login with administrator credentials.
  • Full CRUD (Create, Read, Update, Delete) capabilities for tools in the database.
  • A centralized dashboard to view and manage all user requests.
  • Approve or deny requests, which dynamically updates tool availability.

Database Module

The core of the system, storing all persistent data in a structured MySQL database.

  • users table: Stores user and admin account information and roles.
  • tools table: Contains all information about tools, including name, description, and quantity.
  • requests table: Logs all user requests, their status, and relevant timestamps.
